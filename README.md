# tguerich.github.io

Personal site of Tony Guerich, built with Jekyll and the
[Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme (via `remote_theme`).

Local preview:

    bundle install
    bundle exec jekyll serve --host 0.0.0.0 --port 4000

New articles go in `_posts/` as `YYYY-MM-DD-title.md`.

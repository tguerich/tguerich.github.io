Holder

Verse box

Each set lives in one place: Learn, Review, or the box. Each pocket holds one set; moving a set into a full pocket sends the set already there back to the box. A set moved to Learn puts its first card in the window.

Blank cards: add your own

New cards are numbered within their set, such as John 1 · 1. If the set name is left blank, a chapter becomes its own tab named after it.
